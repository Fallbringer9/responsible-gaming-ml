# Responsible Gaming ML

### Projet pédagogique — Machine Learning, Python et développement assisté par IA

## Présentation du projet

Responsible Gaming ML est un projet personnel réalisé dans le cadre de ma reconversion professionnelle vers le développement logiciel et l'intelligence artificielle.

Fort de mon expérience professionnelle dans l'industrie des casinos, j'ai choisi d'explorer une problématique métier que je connais : l'identification de signaux comportementaux pouvant être associés à des pratiques de jeu à risque.

L'objectif n'est pas de développer un système de détection opérationnel, mais de découvrir concrètement les différentes étapes d'un projet de Machine Learning supervisé, tout en renforçant mes compétences en développement Python.

Ce projet constitue également un support pratique pour ma préparation à la certification **AWS Certified Machine Learning Engineer – Associate (MLA-C01)**.

## Objectifs pédagogiques

Ce projet s'articule autour de trois axes d'apprentissage.

### 1. Machine Learning

Mettre en pratique mes connaissances théoriques à travers un workflow complet de classification supervisée :

- Génération de données synthétiques.
- Analyse exploratoire des données (EDA).
- Préparation des données et séparation Train / Validation / Test.
- Entraînement de modèles de classification.
- Évaluation des performances.
- Compréhension du déséquilibre des classes.
- Expérimentation des hyperparamètres.
- Comparaison et sélection de modèles.

L'objectif est de comprendre les mécanismes fondamentaux du Machine Learning, au-delà de la simple utilisation des bibliothèques.

### 2. Software Engineering

Renforcer mes compétences en développement Python et découvrir les bonnes pratiques utilisées dans des projets modernes :

- Organisation et structuration d'un projet Python.
- Gestion des dépendances avec `uv`.
- Écriture de tests automatisés avec `pytest`.
- Analyse et qualité du code avec `Ruff`.
- Utilisation de Git pour le versionnement.
- Reproductibilité des expérimentations.
- Séparation des responsabilités entre les modules.

Certaines technologies utilisées dans ce projet constituent une première expérience pratique. Ce travail me permet de consolider mes acquis théoriques et de développer progressivement mon autonomie.

### 3. Développement assisté par IA et Harness Engineering

Ce projet est également l'occasion d'expérimenter une approche moderne du développement logiciel avec **OpenAI Codex**, utilisé comme agent de code.

Mon objectif n'est pas simplement de générer du code, mais d'apprendre à collaborer efficacement avec un agent tout en conservant la compréhension et le contrôle du projet.

Cette démarche repose notamment sur :

- L'utilisation d'un fichier `AGENTS.md` pour définir les instructions du projet.
- La formulation de tâches précises et délimitées.
- La définition de contraintes techniques.
- L'utilisation de tests automatisés pour vérifier les modifications.
- L'analyse des résultats et des comportements observés.
- La validation humaine des choix techniques.
- L'identification et la correction des erreurs.

Cette approche constitue une première initiation pratique aux principes du **Harness Engineering** : construire un environnement de travail permettant d'encadrer, guider et vérifier les actions d'un agent de développement.

## Démarche d'apprentissage

Je suis actuellement en phase d'apprentissage pratique du Machine Learning et de certaines méthodes modernes de développement logiciel.

Ce dépôt reflète cette progression.

Il ne cherche pas à démontrer une expertise avancée, mais à documenter une démarche structurée :

1. Comprendre les concepts théoriques.
2. Définir un objectif technique.
3. Expérimenter avec les outils adaptés.
4. Analyser les résultats.
5. Identifier les erreurs et les limites.
6. Améliorer progressivement la qualité du code.

L'utilisation d'un agent de code fait partie intégrante de cet apprentissage. Elle ne remplace pas la compréhension des concepts, la prise de décision ni la vérification des résultats.

## Limites du projet

**Responsible Gaming ML est exclusivement un projet pédagogique.**

Les données utilisées sont entièrement synthétiques et les étiquettes de classification sont générées artificiellement.

Les performances obtenues ne constituent donc pas une preuve de capacité à identifier des comportements de jeu problématiques dans des conditions réelles.

Le modèle n'est pas destiné à être utilisé pour prendre des décisions concernant des joueurs.
